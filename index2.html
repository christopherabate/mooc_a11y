4. Text resizing, reflow and orientation

Users may need to enlarge text or use a narrow viewport. Increasing text size should not make content unusable.

Status

○ Not tested

Interactive test: make the text bigger

Imagine that you need larger text. Use the control to increase the text size.

Important information

The content should remain readable and usable when text is enlarged. Users should not lose information because text overlaps, is clipped or becomes impossible to operate.

Interactive test: can the content reflow?

Reduce the available width. Look for horizontal scrolling, clipped content or controls that become unusable.

Narrow content should reflow into the available space rather than requiring unnecessary two-dimensional scrolling.

Responsive content area

This area is intentionally wide enough to let you observe what happens when the available space becomes narrow.

Remember: 200% text resizing and narrow reflow are related but distinct checks. For web content, test reflow at approximately 320 CSS pixels of available width, corresponding to the narrow reflow condition required by the applicable WCAG criterion.

How to test effectively

Test text resizing, browser zoom, narrow reflow and supported orientations. Check that content remains available and operable.
